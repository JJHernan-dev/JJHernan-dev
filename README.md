# 👋 Sobre mí

Me apasiona la tecnología y disfruto entendiendo **cómo se construyen, administran y protegen los sistemas**.

Mi formación en **Sistemas Microinformáticos y Redes**, **Desarrollo de Aplicaciones Multiplataforma** y **Ciberseguridad** me ha permitido desarrollar un perfil técnico que combina desarrollo de software, administración de sistemas y seguridad.

Trabajo con tecnologías como **Java, Spring Boot, C#/.NET, Linux, Docker y PostgreSQL**, desarrollando proyectos personales que me permiten seguir aprendiendo mientras documento todo el proceso de forma profesional.

---

# 🚀 Proyecto principal

## 🛡️ Mithrandir Sentinel

Herramienta de monitorización defensiva desarrollada en **C# y WPF**, inspirada en el funcionamiento de un SOC.

Permite supervisar conexiones TCP en tiempo real, generar alertas dinámicas y visualizar la actividad de red mediante una interfaz moderna basada en MVVM.

🔗 **Repositorio:**  
https://github.com/JJHernan-dev/Mithrandir-Sentinel
